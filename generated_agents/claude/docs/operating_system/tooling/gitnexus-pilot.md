# GitNexus Pilot

GitNexus is being evaluated as a private-repo-only internal tooling pilot.

## Pilot Rule

GitNexus may be used to improve:

- codebase navigation
- dependency tracing
- artifact-contract analysis
- cross-file debugging

It is not a product dependency.

## Boundary

During the pilot:

- setup and notes remain private
- public docs must not depend on GitNexus
- the public repo must not include GitNexus-specific workflow material

## Decision Gate

Keep GitNexus only if it proves value on real tasks such as:

- pipeline tracing
- control-plane tracing
- artifact contract analysis
- doc/code drift analysis
