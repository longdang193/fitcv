# Audit Evidence Mandate Rule

Formal audit report is required for security or privacy failure, data loss, serious data-quality impact, repeated user-impacting runtime failure, unclear cross-boundary invariant failure, or explicit request. Add supporting evidence files only when report needs them.

Ordinary failures require failing output, root cause, focused regression proof, and fresh verification. They do not require formal audit report or evidence directory.
