# Constraints And Non-Goals

## Constraints

- the private repo remains the development source of truth
- curated publication must not leak private operating-system or agent material
- generated lifecycle contracts and discovery must not become hand-edited truth
- expensive late-stage CV work should stay gated by earlier narrowing and fit decisions

## Non-Goals

- replacing human review with fully autonomous application decisions
- turning generated discovery docs into the primary design surface
- treating the public repo as the primary development environment
