# deterministic-truth-outcome-contract

## Goal

Define accepted, held, blocked, rejected, and skipped meanings as authoritative outcomes.

## Why Now

All downstream observability and agentic work depends on a stable outcome vocabulary.

## Dependencies

semantic-spine-stage-authority-contract

## Shared Surfaces

results.json; pipeline statuses; UI outcome labels

## Notes

This is a first-wave spec candidate.

## Key Deliverables

- Canonical outcome taxonomy defined (accepted, held, blocked, rejected, skipped).
- Outcome semantics mapped to lifecycle transitions and acceptance gates.
