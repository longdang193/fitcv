# Docs Instructions

This directory contains product docs, generated discovery, and operating-system docs.

## Editing Rules

- Follow `docs/operating_system/governance/repo-governance.md`.
- Treat `docs/operating_system/` as human-readable governance guidance. Source
  and tests own executable behavior; `repo_config/` owns machine-enforced policy.
- Keep product docs and operating-system docs separate.
- Update generated discovery from source layers rather than hand-editing generated files.
- Do not make public docs depend on private operating-system materials.
