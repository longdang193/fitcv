# Documentation Update Prompt

Identify canonical owner and active consumers. Update only necessary docs, links, examples, metadata, and navigation. Replace global reads with conditional reads. Do not edit generated output; regenerate it from source. Delete stale duplicate wording, dead references, and unused metadata. Verify links, executable commands, document validators, adapter drift, and publication boundaries when affected.
