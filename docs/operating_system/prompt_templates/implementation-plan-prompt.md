# Implementation Plan Prompt

From approved design decisions or direct approved scope, create right-sized tasks with purpose, specification coverage, exact files and symbols, dependencies, steps, required skills, verification commands, and exit criteria. State the execution approach. Use parallel lanes only for disjoint write sets and serialize shared-file ownership. Preserve rollback and safety boundaries.
