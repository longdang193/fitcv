# Parallel Change Prompt

Prove lanes independent. Assign disjoint files and exact deliverables. Writable
lanes require isolated worktrees; shared-workspace lanes stay read-only. Give
each lane one validated packet. Verify each lane, reconcile once, resolve
conflicts source-first, and run combined verification.
