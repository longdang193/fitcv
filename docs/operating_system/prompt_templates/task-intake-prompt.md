# Task Intake Prompt

Inspect current source and state. State requested outcome, preserved invariants,
risks, and smallest truthful route: direct execution, brainstorming, spec,
plan, or optional roadmap plus only the specs or plans it needs. Ask only
blocking questions. Do not create an artifact merely to connect other artifacts.
